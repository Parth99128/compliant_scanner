# docs/legal-source/

Authoritative text of the Legal Metrology (Packaged Commodities) Rules, 2011.

- `LMPC-Rules-2011_WB-mirror.pdf` (43 pages) — **primary, verified readable copy**,
  hosted on `wbconsumers.gov.in` (West Bengal Consumer Affairs mirror of the
  central Rules). Rule 7 (principal display panel, Tables I & II) is on
  **pp. 8–9**; cross-checked verbatim into `app/services/rule_engine.py`
  (`citation_verified=True` on all `LMPC-7.*` results).
- Meghalaya backup mirror (same central text, unreachable from this machine —
  TLS handshake rejected for automated clients; retry in a browser):
  `https://megweights.gov.in/acts/Legal-Metrology-Packaged-Commodities-Rules-2011.pdf`
- Official consolidated book with all amendments (open manually in a browser):
  `https://consumeraffairs.gov.in/public/upload/admin/cmsfiles/whatsnews/Book_on_Legal_Metrology_Packaged_Commodities_Rules,2011_with_all_amendments_whatsnews.pdf`

Verified so far against this text: Rule 7 (pp. 8–9); Rule 6(1)(a)–(e) + Rule 2(m)
MRP manner (pp. 3, 5–6). Still unverified: consumer-care wording and the literal
"country of origin" phrase — both absent from the base 2011 text (post-2011
amendments); the amendments book above is needed to confirm them.
